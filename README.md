# Памятка первокурсника

Одностраничный сайт-памятка для первокурсников Самарского университета.
Подготовлен Советом старост. Angular 21 + TypeScript, без бэкенда — только фронт.

- Одна страница, разделы — обычные якоря (`#study`, `#money`, …), ссылку на раздел можно кинуть в чат.
- Поиск по всему тексту памятки (клавиша <kbd>/</kbd> или <kbd>Ctrl</kbd>+<kbd>K</kbd>).
- Светлая и тёмная темы, выбор запоминается.
- Адаптив: телефон, планшет, десктоп.

---

## Как запустить

Нужен Node.js 20.19+ / 22.12+ / 24+ (проверить: `node -v`).

```bash
npm install
npm start
```

Откроется на <http://localhost:4200>, страница сама перезагружается при правках.

### В WebStorm

1. `File → Open` → выбрать папку `starosta-guide`.
2. Дождаться, пока WebStorm подхватит `package.json` и предложит `npm install` (или запустить вручную: правый клик по `package.json` → `Run 'npm install'`).
3. В панели `npm` (справа или `View → Tool Windows → npm`) двойной клик по `start`.

### Сборка

```bash
npm run build
```

Готовые файлы появятся в `dist/starosta-guide/browser` — это статика, её можно
положить на любой хостинг.

## Как править контент

Почти всё правится в одном файле — `src/app/data/guide-data.ts`.
Вёрстку трогать не нужно: компоненты просто отрисовывают блоки.

Добавить раздел:

```ts
{
  id: 'dorm',                       // якорь: #dorm
  title: 'Общежитие',
  teaser: 'Заселение, пропуск, что взять с собой',
  glyph: 'door',                    // значок из src/app/components/glyph/glyph.ts
  blocks: [
    { kind: 'lead', text: 'Короткий вводный абзац.' },
    { kind: 'steps', items: [{ title: 'Шаг первый', note: 'Пояснение' }] },
  ],
}
```

Раздел сам появится в верхней ленте, в плитках «С чего начать» и в поиске.

Доступные типы блоков (полный список с полями — в `src/app/models/guide.model.ts`):

| `kind`     | Для чего                                     |
| ---------- | -------------------------------------------- |
| `lead`     | крупный вводный абзац                        |
| `text`     | обычный абзац                                |
| `list`     | список, маркированный или нумерованный       |
| `steps`    | пошаговый алгоритм с номерами                |
| `defs`     | «термин — расшифровка»                       |
| `table`    | таблица, можно с заголовками групп строк     |
| `cards`    | карточки контактов: адрес, телефон, почта    |
| `gallery`  | картинки с подписями                         |
| `callout`  | выноска: `info` (зелёная) или `warn` (тёплая) |
| `links`    | внешние ссылки                               |
| `tags`     | набор «плашек»                               |
| `timeline` | хронология «год — событие»                   |

### Логотип

Логотип лежит в двух вариантах: `public/assets/logo.png` (для светлой темы) и
`public/assets/logo-dark.png` (белый текст, для тёмной). Плюс `mark.png` /
`mark-dark.png` — только знак, без надписи. Чтобы заменить — просто положи
файлы с теми же именами; размеры подстроятся сами.

### Цвета

Вся палитра — CSS-переменные в начале `src/styles.css`: сначала светлая тема
в `:root`, потом тёмная в `:root[data-theme='dark']`. Меняешь там — меняется
везде.

## Куда выложить

### GitHub Pages (уже настроено)

В репозитории лежит `.github/workflows/deploy.yml`. Что нужно сделать один раз:

1. Залить проект в репозиторий на GitHub, ветка `main`.
2. `Settings → Pages → Build and deployment → Source` = **GitHub Actions**.
3. Пушнуть в `main` — вкладка `Actions` покажет сборку.

Сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.
`base-href` workflow подставляет сам из имени репозитория, править ничего не надо.

### Другие бесплатные варианты

Все три умеют собирать Angular сами: подключаешь репозиторий, они видят
`package.json`, запускают `npm run build` и раздают папку с готовой сборкой.

| Сервис           | Что указать                                                    | Плюсы                                                                    |
| ---------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **Netlify**      | build: `npm run build`, publish: `dist/starosta-guide/browser` | ссылка вида `имя.netlify.app`, деплой с каждого пуша, превью пул-реквестов |
| **Vercel**       | framework: Angular, остальное определит сам                     | быстрый CDN, свой домен бесплатно                                        |
| **Cloudflare Pages** | build: `npm run build`, output: `dist/starosta-guide/browser` | щедрый бесплатный тариф, хорошая скорость в России                       |

В отличие от GitHub Pages, там сайт лежит в корне домена — `base-href` менять не нужно.
